# 🚀 AlmaBoard

Sistema backend inspirado em plataformas de organização de tarefas como Trello e Jira, desenvolvido com Java e Spring Boot durante o Bootcamp AlmaViva Solutions.

---

# 📌 Objetivo

O projeto foi criado com foco em:

- Desenvolvimento backend com Spring Boot
- Estruturação de APIs REST
- Aplicação de Programação Orientada a Objetos
- Organização em arquitetura em camadas
- Persistência de dados com JPA/Hibernate
- Boas práticas de versionamento com Git e GitHub

---

# 🛠️ Tecnologias Utilizadas

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- Maven
- H2 Database
- Hibernate
